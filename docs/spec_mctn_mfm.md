## MCTN — Found in Translation (AAAI 2019, pp.6892-6899)

### 论文定义的结构

三模态用**层级式**两级翻译（论文 Figure 3）：

1. **第一级**：源模态 `X^S`（语言）与目标 `X^T1`（视觉）之间做**循环翻译**
   - `E_{S→T}= f_θe(X^S)`，`X̂^T = f_θd(E_{S→T})` … (6)(7)
   - 回译：`E_{T→S} = f_θe(X̂^T)`，`X̂^S = f_θd(E_{T→S})` … (8)
   - **编码器与解码器在正向与回译中共享**（同一个 `f_θe`/`f_θd`）
2. **第二级**：把 `E_{S⇔T1}` 再翻译到 `X^T2`（声学），得 `E_{(S⇔T1)→T2}`
3. **预测**：`ŷ = g_w(E_{(S⇔T1)→T2})` … (14)

编码器输出是**全部时间步隐状态的拼接** `E_{S→T} = [h_1,…,h_L]`（式 10）。Seq2Seq 带 Bahdanau 注意力，解码用 **beam search**（式 12）。

### 目标函数（式 15-19）

```
L = λ_t · L_t + λ_c · L_c + L_p
L_t = E[ℓ_XT(X̂^T, X^T)]      # 正向翻译损失，MSE
L_c = E[ℓ_XS(X̂^S, X^S)]      # 循环一致性损失，MSE
L_p = E[ℓ_y(ŷ, y)]           # 预测损失
```

`λ_t`、`λ_c` 论文写明是**超参**，未给具体值。

### 论文的核心主张（这才是要检验的东西）

> **测试时只需要源模态**（式 20-21）。"这是可能的，因为编码器已被训练成把源模态翻译进一个同时捕获源与目标信息的联合表征。"

### 与 MMSA 实现的偏离（已逐行核对）

| # | 论文 | MMSA | 影响 |
|---|---|---|---|
| 1 | 解码用 beam search（式 12） | 无 beam search，逐步贪心 | 翻译质量 → 间接影响表征 |
| 2 | `λ_t`、`λ_c` 是超参 | **硬编码 0.1 / 0.1**（`0.1*loss_v+0.1*loss_t+0.1*loss_a+1.0*loss_y`） | 目标函数权重不可调 |
| 3 | teacher forcing 是 seq2seq 的标准机制 | **空操作**：`dec_input = trg[t] if teacher_force else top1`，两分支同值（`top1 = trg[t,:]`），`random.random()` 只消耗 RNG | **解码器永远吃 ground-truth 目标帧**，翻译损失的训练动力学与论文不同 |
| 4 | — | 配置里 `update_epochs` / `contrast` / `mem_size` / `add_va` **其 trainer 一个都没读** | 死键，不影响数值但会误导读者 |

**一处需要在实现时确认、不要想当然**：MMSA 的预测路径 `join` 来自 `encoder2(encoder1(text))`，**不依赖 audio/vision**——这一点与论文"测试只需源模态"是一致的。音视频只通过翻译损失进入训练。**实现时必须保持这个性质，并写一个断言测试**：把 audio/vision 换成随机张量，预测输出必须逐比特不变。

### 超参来源

论文正文**没有给任何数值超参**（无 lr、无隐藏维、无优化器）——按调研台账的判据，这是 `reimpl-partial` 的触发条件。但**作者实现可用**（[hainow/MCTN](https://github.com/hainow/MCTN)，200），故按参照优先级第 1 级取超参，并在 docstring 注明"结构取自论文，超参取自作者实现"。

MMSA 的 MOSI 配置作为对照记录：`init_lr 1e-4 / batch 32 / grad_clip 1.0 / hid_dim 32 / output_dim 768 / max_seq_len 50 / early_stop 8`，选择量 `KeyEval = Loss`（**复合损失**，不是 MAE）。

## MFM — Learning Factorized Multimodal Representations (ICLR 2019)

### 论文定义的结构

把多模态表征**因子化**为两类：

- **多模态判别因子 `F_y`**：所有模态共享，承载判别任务所需的联合信息
- **模态专属生成因子 `F_a{1..M}`**：每个模态各一份，承载生成该模态所需的信息

生成网络与推断网络配对（论文 Figure 1a/1b），联合分布按条件独立假设分解。目标是 ELBO 形式：判别项 + 生成（重构）项 + 对潜变量分布的正则（实现中用 **MMD** 而非 KL）。

### 论文的核心主张

1. 判别因子在六个多模态时序数据集上达到 SOTA 或竞争性能
2. **可从已观测模态重构缺失模态，而判别性能不显著下降**
3. 因子化表征具备可解释性（信息论与梯度两种归因）

### 与 MMSA 实现的偏离

| # | 论文 | MMSA | 影响 |
|---|---|---|---|
| 1 | `learning_rate` 应生效 | **配置里的 `0.002` 从未生效**——trainer 的 `optim.Adam(model.parameters(), weight_decay=...)` **没传 lr**，实际用 Adam 默认 1e-3 | 真实学习率与配置声明不符 |
| 2 | 主张 2（缺失模态重构） | **`missing_loss = 0.0` 硬编码**，从不计算 | **论文最有特色的那条主张，在 MMSA 版里根本没有被实现** |
| 3 | MMD 用于正则 | `loss_MMD` 里 `torch.randn` 走全局 RNG 且先在 CPU 生成再搬设备 | 影响可复现性口径，需在我们的实现里改用带 generator 的采样 |
| 4 | 编码器 | 复用 `MFN` 作为 `mfn_encoder`，取其 `'L'` 输出 | 我们已有 MFN，可直接复用 |

### 超参来源

MMSA 的 MOSI 配置（含 `zy/zl/za/zv`、`fy/fl/fa/fv` 各维度、四组 dropout、`lda_mmd 100`、`lda_xl 0.5 / lda_xa 0.01 / lda_xv 0.5`、`memsize 64`、`windowsize 2`、五组 NN/gamma/out 配置、bs 64）。**作者实现可用**（[pliang279/factorized](https://github.com/pliang279/factorized/)，200），冲突时以作者实现为准并记录差异。

**论文用 CMU-MultimodalSDK 特征（GloVe 系），不是 MMSA 的 BERT 特征**，且写明"所有基线都做了大范围超参搜索后重训"。故原论文数字与我们不可直接比——与验收标准"参照 MMSA 表而非原论文"的理由一致。

## 两者共同的协议问题

**`KeyEval` 都是 `Loss`**，即按**复合损失**选模型（MFM 是 disc+gen+mmd，MCTN 是 0.1×三路重构+L1），不是按 MAE。我们的 `--select-on` 目前只接受标准指标名。三个选项：

- A：扩展 `--select-on` 支持 `total_loss`（模型自报的复合损失）
- B：按我们的默认 `mae` 选，把差异记为已知协议差异
- C：两种都跑，作为一个消融组

**建议 A**，理由是 ALMT 已有先例（`--select-on mse`，因为那是参照的 KeyEval 所测），且这是"同协议才可比"的要求。**但 A 需要改 trainer，属判据外的基础设施改动，先请确认。**

## 验收计划（两模型相同）

1. **从论文实现结构与目标函数**，超参取作者实现，docstring 注明每一项的出处
2. **数值等价测试**（约定 5）：权重复制后与 MMSA 版逐元素比对。**预期不等价**——因为上面列的偏离是真实差异，不是 bug。故等价测试的用法是：**先复现 MMSA 版以确认我们的骨架无误，再切换到论文版并记录差异带来的数值变化**
3. **不变量断言**：MCTN 的"测试只需源模态"要有断言测试（换随机 audio/vision，预测不变）

   - MCTN：测试时丢弃目标模态，性能下降多少？论文说不需要，**我们量它**
   - MFM：MMSA 版没实现的缺失模态重构，**补上并测主张 2**
6. 进 `reproduce_all.sh`、`survey.md` 台账 A、`storyline.md`

## 已确认的三项决定（2026-08-02）

1. **不做 `--select-on total_loss`。** 两模型仍按本仓库默认的 valid MAE 选模型。**这与参照的 `KeyEval = Loss` 是一处已知协议差异，必须写进两个模型的 docstring 与 storyline**，不得默默略过。
2. **做缺失模态重构**（MFM 论文主张 2）。MMSA 版把 `missing_loss` 硬编码为 0，从未实现——补上它意味着本轮从"复现 MMSA"跨到"复现论文"，**这是本轮最有价值的部分**：一条被广泛引用却从未在社区参照实现中执行过的主张，首次被检验。
3. **两个版本都建组**：`*_mosi`（MMSA 可比版）与 `*_mosi_paper`（论文忠实版），同 `mult_mosi_posenc` / `ef_lstm_mosi_2021config` 的模式。**验收判据只对可比版生效**；论文版作为对照，回答"忠实论文值多少分"。
