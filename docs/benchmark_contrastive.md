# 对比学习方向的 8 篇对标

老师的要求是「复现 8 篇含对比学习的论文做对标」，没有指定哪 8 篇，由我们自己定。
这份文档定名单、定每篇的对标口径、记进度。**数字进表之前必须标清楚它是哪一档**——
把"我们跑出来的"和"论文自己报的"并列在一张无标注的表里，是这个方向最容易犯、
也最难被外人发现的错误。

## 名单与分档

选取标准：**(a) 方法里确有对比学习项**（不是任意的辅助损失）、**(b) 在 CMU-MOSI /
MOSEI 上报了回归指标**（否则与我们的协议无法并列）、**(c) 覆盖 2021-2024**，
且优先选**有公开代码**的——能跑通的才叫复现。

| # | 论文 | 会议/年份 | 对比学习是什么 | 代码 | 档 |
|---|---|---|---|---|---|
| 1 | MMIM | EMNLP 2021 | 分层互信息最大化，两个 InfoNCE 形式的下界项 | 有（`declare-lab/Multimodal-Infomax`） | **A** |
| 2 | ConFEDE | ACL 2023 | 特征分解 + 样本间对比（`pytorch_metric_learning`） | 有（`XpastaX/ConFEDE`） | **A** |
| 3 | HSCL | MMM 2024 | 分层有监督对比（模态内 / 模态间 / 样本间） | 有（`Turdidae810/HSCL`） | **A** |
| 4 | UniMSE | EMNLP 2022 | 模态间 + 样本间对比，统一 MSA 与 ERC 标签空间 | 有（`LeMei/UniMSE`） | **B** |
| 5 | HyCon | IEEE TAFFC 2022 | 模态内/模态间对比 + 半对比 | 未公开 | **C** |
| 6 | ConKI | ACL Findings 2023 | 知识注入 + 三层次对比（类型内/跨模态/跨样本） | 未公开 | **C** |
| 7 | CMSBERT-CLR | ICASSP 2022 | 上下文驱动的模态偏移 + 对比对齐 | 未公开 | **C** |
| 8 | MMCL | arXiv 2210.14556 | 单模态对比编码 + 跨模态对比预测 | 未公开 | **C** |

- **A 档 = 在我们自己 sha256 校验过的特征上真的跑起来了。** 这是唯一能和我们自己的
  结果同表并列的档。
- **B 档 = 代码公开、值得移植，但工作量单独排期。** UniMSE 是 T5 骨干、还要 MELD /
  IEMOCAP 两个额外数据集与统一标签空间，不是一天的活。
- **C 档 = 只能引用论文自己报的数字，一律标注「待检验的主张」。** 不是怀疑作者，
  而是这些数字来自各自的特征、划分与选模协议，与我们的不可比——这一点本项目已经
  实测过：同一个 MMIM，我们的实现比 MMSA 的好约 1 个标准差，原因至今没定位
  （`investigations.md#mmim-mosei-vs-mmsa`）。**跨实现的 0.01 量级差异说明不了方法优劣。**

## 对标口径（A 档）

每篇走同一条流水线，缺哪一步就说缺哪一步：

1. **跑通**：用原作者代码 + 我们的特征，跑到它自己落盘出指标。
   - 「看见指标在滚」不算跑通，得跑到它写出文件——ConFEDE 那个少建目录的 bug
     是在第几十轮才炸的（`investigations.md#confede-missing-ckpt-dir`）。
2. **与它论文报告值比**：差多少、差在哪。特征已经同源，所以差异只可能来自协议
   （选模、轮数、seed、指标定义）。
3. **移植进我们的注册表**：`@register_model`，走我们的训练循环与评测。
4. **数值等价测试**：权重复制 + 前向比对，与 `check_almt_equivalence.py` /
   `check_mmim_equivalence.py` 同法。**这一步不能省**——ALMT 那个错误版本指标
   全面优于参照却验收通过，就是靠它抓出来的。
5. **多 seed 复现**：`--seeds 42..46`，报 mean ± 样本标准差（约定 1）。

**喂数据的方向是固定的：改我们的数据形状去适配它们的代码，不改它们的代码。**
两边跑同一份特征，指标差异才不能归因于输入。SDK 那一系的布局转换在
`scripts/adapt_features_sdk.py`，路上踩到的 padding 坑见
`investigations.md#mmsa-padding-not-zero`。

| # | 论文 | 1 跑通 | 2 比论文值 | 3 移植 | 4 等价测试 | 5 多 seed |

| 1 | MMIM | ✅ | ⚠️ 见下 | ✅ | ✅ 最大绝对差 0.000e+00 | ✅ |
| 2 | ConFEDE | 进行中 | | | | |
| 3 | HSCL | 数据就绪 | | | | |
| 4 | UniMSE | 未排期 | | | | |
| 5-8 | HyCon / ConKI / CMSBERT-CLR / MMCL | — 无代码，只引用报告值 | | | | |

**第 2 步在 MMIM 上还没按字面做完，这里说清楚。** 我们比的是**自己跑原作者代码**
得到的参照值（`0.7452 / 0.7339†`，见 `experiments.md`），**不是论文表格里的数字**。
就复现而言这个参照更强——它带方差，而论文表里是单个数；但"与论文报告值比"这一栏
要的是另一件事，那栏还欠着。

论文表格数字**一律从 PDF 抄录、注明出处页**，不凭记忆填。这件事对 5-8 那四篇也一样
必须做，所以放在一起做一次，而不是逐篇零敲——凭记忆写一个 SOTA 数字，是这类对标表
最容易混进去的假信息。

MMIM 那一行的详情在 `storyline.md` 与 `investigations.md#mmim-equivalence`；顺带
得到的一条结论是**它论文里那两个对比项在 MOSEI 上显著有害**（|d|=1.39），而那是在
一个已证明与 MMSA 逐比特一致的模型上测的（`#mosei-contrast-harmful`）。这正是做
对标的价值：能跑通、能等价、才敢说这种话。
